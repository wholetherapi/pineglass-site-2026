Tesserae audits provenance for tiled raster products: it walks the tile graph, checks the
declared lineage against content hashes and emits a machine-readable audit report.  The
toolkit was accepted for the Journal of Marine Data Systems tool track.

The released repository includes the command-line interface, the tile graph library and a
sample manifest for integration testing.
